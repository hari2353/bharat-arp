# Code of Conduct

## Our Standard

Contributors and maintainers are expected to be respectful, constructive, and
professional. We welcome people of all backgrounds and experience levels.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate privacy violations, doxxing, sexualized conduct, and publishing
private information without permission.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through
the GitHub repository owner profile. Reports will be reviewed in good faith and
handled as confidentially as practical.
